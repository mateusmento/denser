# DocumentSurface

Layout shell for documents: optional `#header` slot and a scrollable default slot for the editor. Containers fill the header with `DocumentHeaderContainer` and the body with `DocumentEditor` (properties via `#properties` slot).

Editor states (loading, error, ready, …) live on **DocumentEditor** — see that story group for the full matrix.
