# DocumentSurface

The document **canvas**: header, in-flow title, and body. Spec: `docs/ui-surfaces/document.md`.

This page is **Docs** (`viewMode: "docs"`). It inlines every story below in **one** scrolling document. Canvas (`viewMode: "story"`) shows a single story in the preview iframe.

If each story used `h-svh` here, this page would be six viewports tall — Ready, then EmptyNew, then ReadOnly, and so on, each as tall as the docs window. The preview decorator therefore caps Docs at `40rem` and only fills the iframe on Canvas (`fullHeight`).
